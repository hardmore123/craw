## 这个版本做了什么（相对 v1.3）

### 新增：网页前后端
- 本地服务 `python -m cert_verify.web`，仅绑 `127.0.0.1:8756`（端口占用自动 +1）。
- 双击 `启动网页.bat` 即用；浏览器自动打开。
- 四步界面：上传 xlsx → 确认工作表/列映射 → 实时进度（当前工作表/证书号/机构 + 统计，可取消）→
  结果表（按状态着色、可筛选、点行看字段明细、下载结果）。
- UL 登录：网页上点「UL 登录」按钮弹本机 Edge，登录态存本地、不外泄。

### 新增：结果标红与结构化比对
- `compare.py` 新增 `compare_fields()`：字段级结论，作为网页展示 / M 列文案 / Excel 标红的**唯一判断来源**。
- `verifier.py`（新核心）：逐行核对、可上报进度、可取消、产出带列定位的结果。
- `excel_writer.py`（新）：在**原文件副本**上写结论 + 对真不一致字段设**红色字体**（保留原字体其他属性），
  失败自动降级为仅写值。原文件字节保持不变。

### 判定规则（未变，继续遵守）
- 只有「真不一致（MISMATCH）」才标红。
- 「网站无此项」「表格未填」「未查到 / 被拦截 / 失败」都不标红。
- UL 列表页没有精确型号/标准，按「网站无此项」处理，不拿 CCN/文档名冒充型号。

## 本次修复的三个网页使用问题

1. **「字段明细」白框一打开就挡住页面、关不掉**
   - 原因：`.modal { display:flex }` 写在 `.hidden { display:none }` 之后，同优先级被覆盖，`hidden` 失效。
   - 修复：`.hidden, .modal.hidden { display:none !important; }`。默认隐藏，点行才弹、点 × 可关。

2. **UL 每查一行就重开一次浏览器 → 又慢又像卡死**
   - 修复：整个任务**复用同一个浏览器会话**，结束时统一关闭（`ProviderRouter.close()` + 引擎 finally）。

3. **浏览器开得太早（拒绝连接）/ 黑窗口被当弹窗关掉 → 服务停了**
   - 修复：后台线程延迟打开浏览器 + `os.startfile` 兜底；`启动网页.bat` 和控制台醒目提示
     「使用期间请勿关闭本窗口」。

## 使用前提
- 查 **VDE**：需先开 VPN/加速器（工具自动走系统代理）。
- 查 **UL**：需在网页上点「UL 登录」先登一次（需已装 Playwright）。
- 查 **TÜV Rheinland**：直连即可。

## 已知限制
- Certipedia（TÜV）不公开「生产厂」；VDE 默认接口不含标准/生产厂 → 记「网站无此项」。
- 中英文混写的制造商/地址无法自动判等，会标为不一致交人工看。

## 测试
- 离线测试全部通过：`test_compare_fields.py`、`test_excel_writer.py`、`test_web_flow.py`、`test_vde_parse.py`。
- 实机（开代理 + UL 已登录）小样：VDE、UL 各条均查到，标红/下载/原文件不变符合预期。
