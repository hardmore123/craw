## 本次重点（相对 v2.4）

### 1. 修复重大 Bug：制造商列被错配到「厂家」列，导致每行都判不一致
- 现象：核对结果里几乎所有行都显示「制造商不一致」，抓取表的制造商列也没显示官网抓到的值。
- 根因：报备表里 **B 列「厂家」是内部供应商标记（第一厂家 / 扩点厂家），不是制造商**；
  真正的制造商是 **G 列「商标/制造商」**。旧的列识别把关键词「厂家」当成了制造商，
  且 B 列在前，于是把制造商错认成 B 列 →
  - 拿「第一厂家」和官网「LITTELFUSE INC」比 → 全部不一致；
  - 官网抓到的制造商被写进了错误的 B 列，G 列自然没变。
- 修复：列识别改为**按关键词优先级匹配**，「商标/制造商 / manufacturer」优先于「厂家」，
  正确指向 G 列。已用真实报备表验证：UL/CB/CB-UL/X电容等各表制造商均正确落在 G 列。

### 2. 列映射界面重做，更直观易懂
- 上传后**按表头文字自动识别**每列含义（证书号/认证类别/制造商/型号/标准），一般无需手改。
  连原先要手动改的「认证类别CB-UL」表（证书号=J、机构列=K）现在也能自动认出。
- 用**下拉选列**（显示「G 列 — 商标/制造商」）替代手填 Excel 列字母。
- 每个字段带状态徽标：✓ 自动识别 / 默认猜测·请核对 / 未识别·请选择；
  每张表顶部给出识别情况总结；识别不到时不再乱填默认列，避免误导。
- 「预览这张表的前几行」用清爽的小表格展示（列字母 + 表头 + 示例数据）。
- 不常用字段（结果列/生产厂/证书状态）收进折叠区，主界面更简洁。

### 3. 查询间隔 / 随机抖动 可在网页自主设置（默认 1 秒 + 抖动 1 秒）
- 新增「查询间隔」设置：固定间隔（快速 1s / 稳妥 5s / 保守 15s / 自定义）
  ＋ 随机抖动（0～N 秒，默认 1s）。每条实际等待 = 固定间隔 ＋ 0~抖动 的随机秒数。
- 贯穿全链路可配置：网页 → RunConfig → ProviderRouter → HttpClient(VDE/TÜV) 与 UlProvider(UL)。
- 注意：默认 1s 较快，若批量核对被官网风控/封 IP，请调回 5~15 秒。

### 4. 抓取表：官网抓取值改用「天蓝色」字标注
- 抓取结果表里，从官网抓到的制造商/型号/标准等值用**天蓝色（#00B0F0）**字标出，
  与表格原值（黑字）一眼区分；官网无此项写「(官网未提供)」不上色。

## 使用与迁移
- 启动网页：双击 `启动网页.bat`（或 `一键启动.bat`，新电脑首次用）。
- 换电脑：见包内 `迁移到新电脑说明.md`。
- 每次改动后重新打包：`python cert_verify\build_package.py`。

## 已知限制（延续）
- VDE 默认接口不返回「标准」；UL 列表页无「型号/标准」；官网普遍不公开「生产厂」
  → 这些记「网站无此项」，不判不一致。
- 中英文混写的制造商（表格「东莞」vs 官网「Dongguan」）会判不一致，需人工看。
- 查境外官网需开 VPN / 加速器；UL 需先在网页点「UL 登录」登一次。
