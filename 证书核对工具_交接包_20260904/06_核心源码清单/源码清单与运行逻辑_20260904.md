## 二、运行逻辑串联（端到端）

### 逻辑 A：网页版完整流程

```
用户浏览器打开 http://127.0.0.1:8756
    │
    ├── [1] 上传 xlsx → POST /api/upload
    │       server.py: 保存到 web/_work/、检测加密(is_encrypted)→解密(decrypt_file)
    │       → openpyxl 解析 → 返回 sheets + 列预览
    │
    ├── [2] 前端 autoDetect 按表头关键词自动识别列 (app.js)
    │       用户确认/手动改列映射 → 填运行参数（limit/proxy/interval/jitter）
    │
    ├── [3] 开始核对 → POST /api/run
    │       server.py → tasks.py: TaskManager.create_and_start()
    │       → 后台线程跑 _MultiMapEngine（每 sheet 不同列映射）
    │
    ├── [4] 后台线程逐行核对（verifier.py 的 VerifyEngine.iter_rows）
    │       每行：
    │       a. 读 xlsx 取证书号 + 五个待比对字段值
    │       b. ProviderRouter.resolve(cert_no, agency_hint) → 选 Provider
    │       c. Provider.query(cert_no) → CertRecord（各机构网站返回）
    │          - TÜV: HttpClient.get(certipedia 详情页) → 解析 HTML
    │          - VDE: HttpClient.get(restSearch JSON) → parse JSON
    │          - UL: UlSession(Playwright Edge) → suggest→qm→results HTML
    │       d. compare_fields(sheet_row, rec) → list[FieldVerdict]
    │          - cmp_company: 归一化→包含→相似度≥0.86
    │          - cmp_model: 集合交集→通配匹配→相似度≥0.9
    │          - cmp_standard: 标准号集合→精确→去年份核心号
    │          - cmp_status: 映射有效/失效
    │       e. summarize_fields() → 组装 verdict_text（M 列文案）
    │       f. 产出 RowOutcome（含字段级 verdict + 列定位）
    │       g. 检查 cancel Event → 遇 BLOCKED 且 stop_on_blocked → 停
    │
    ├── [5] 前端轮询 → GET /api/progress?id=&offset=
    │       返回增量 new_rows + 统计 + 当前进度
    │
    └── [6] 完成 → 产出两份文件 + GET /api/download?id=&kind=diff|crawl
            excel_writer.write_results()  → 对比表（红字标不一致）
            excel_writer.write_crawl_copy() → 抓取表（蓝字填官网值）
            原文件不动，结果存 web/_work/<task_id>/
```

### 逻辑 B：命令行流程

## 三、路由规则运行逻辑（ProviderRouter.resolve）

```
resolve(cert_no, agency_hint):
    1. 证书号显式前缀（最高优先级）
       - "TUV …" → TUV-Rheinland
       - "VDE …" → VDE
       - "UL …"  → UL
       - "ENEC …" → None（不搜索，标"人工核对"）

    2. 无前缀 → 按 agency_hint 认证类别列
       - 含 "ul" → UL（包括 CB/UL、UL/CB、CB-UL）
       - 含 "vde" → VDE
       - 含 "tüv"/"tuv"/"rheinland"/"莱茵" → TUV-Rheinland
       - 含 "cb"（纯 CB）→ VDE（VDE 是 CB 证书核对源）

    3. 都判不出 → 按证书号形态猜测
       - ^\d{7,8}(-\d+)*$ 或 ^(HA|NA)\d{6,8}$ → VDE
       - ^(E|MH|SA|QQ|LR|AU)\d{4,7}$ → UL
       - ^[A-Z]{1,3}\d{7,10}$ 或 ^\d{8}$ → TUV

    特殊：不含数字的证书号（如 "Tested with Equipment"）→ unsupported 跳过
```
