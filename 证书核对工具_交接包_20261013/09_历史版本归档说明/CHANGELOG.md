## v2.6（2026-08-14）

### 改进
- **智能代理探测**：`resolve_proxy()` 探测到代理候选后先 TCP 测端口是否在监听——
  活着才用（VPN 开），死了自动直连（VPN 关），未设则直连。
  解决"VPN 已关但 Windows 系统代理设置残留指向死端口 7877 → 全部查询失败"的坑。
- 背景：本机实测 TÜV / VDE / UL 三站**无需 VPN 即可直连**（UL 仍需浏览器过 Cloudflare）。
- 网页"代理地址"提示改为"留空=直连(通常无需VPN)"。

## v2.5（2026-08-12）

### 修复
- **制造商列被错配到「厂家」列，导致几乎每行都判「制造商不一致」、抓取表制造商列不显示官网值**：
  报备表 B 列「厂家」是内部供应商标记（第一厂家/扩点厂家），真正的制造商是 G 列「商标/制造商」。
  旧列识别把「厂家」当制造商且 B 列在前 → 错认 B 列。改为**按关键词优先级识别**，
  「商标/制造商 / manufacturer」优先于「厂家」，正确指向 G 列。已用真实报备表各 sheet 验证。

### 新增 / 改进
- **列映射界面重做**：上传后按表头文字**自动识别**各列（含原先需手改的 CB-UL 表）；
  用**下拉选列**替代手填列字母；字段带识别状态徽标与每表识别总结；预览改为清爽小表格；
  不常用字段折叠。识别不到不再乱填默认列。
- **查询间隔可在网页自主设置**：固定间隔（1/5/15/自定义秒）＋随机抖动（默认 1 秒），
  贯穿 RunConfig → ProviderRouter → HttpClient(VDE/TÜV) 与 UlProvider(UL)。默认 1s+抖动1s。
- **抓取表官网值改用天蓝色（#00B0F0）字标注**，与表格原值区分。

### 约束（延续）
- 原文件不可变，结果另存副本；仅真不一致标红；敏感数据（UL 登录态）不打包、不经接口外泄。

## v2.0（2026-08-06）

### 新增
- 本地网页前后端（`cert_verify/web/`）：上传 → 列映射 → 实时进度 → 结果表 → 下载副本。
- 启动入口 `python -m cert_verify.web` 与 `启动网页.bat`（仅绑 127.0.0.1:8756，端口占用自动 +1）。
- 核对内核 `verifier.py`（可上报进度/可取消/字段级结论，网页与命令行共用）。
- Excel 写入层 `excel_writer.py`：原文件副本上写结论 + 真不一致字段**红色字体**标注，含降级。
- `compare.py` 新增 `compare_fields()`：字段级比对，作为展示/文案/标红的唯一判断来源。
- 离线测试：`test_compare_fields.py`、`test_excel_writer.py`、`test_web_flow.py`。

### 修复
- 「字段明细」弹层因 CSS 优先级问题一直显示且关不掉 → `.hidden` 提权。
- UL 批量核对每行重启浏览器导致极慢/卡死 → 复用同一浏览器会话并在结束时释放。
- 浏览器自动打开过早导致「拒绝连接」/ 黑窗口被误关导致服务停止 → 延迟打开 + 兜底 + 醒目提示。

### 约束（延续）
- 原文件不可变，结果另存副本；仅真不一致标红；敏感数据不打包、不经接口外泄。
