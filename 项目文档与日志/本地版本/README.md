# 本地版本文档（Windows）

面向在本机 Windows 上做开发、打包和离线验证的人。本机使用 Python 3.12。

## 文件清单

| 文件 | 用途 |
|---|---|
| `HANDOFF_交接文档.md` | 新人接手第一篇：项目位置、依赖、代理、UL 登录、常用命令 |
| `周报_证书核对工具.md` | 本周进展与下一步计划 |
| `半月报_证书核对工具.md` | 半月阶段性总结与未来方向 |
| `v2.7打包日志.txt` | v2.7 交付包打包结果与文件核对 |
| `自测报告.txt` | 端到端离线自测（造样例→抓取→比对→写回）结果 |
| `VDE解析与比对测试报告.txt` | VDE 解析器离线断言测试结果 |
| `导出两表测试日志.txt` | 导出两表脚本在本地的运行日志 |
