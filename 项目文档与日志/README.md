# 项目文档与日志

## 分类

### `近期日志/`
保存最近一次部署、解密、UL、网页上传、打包和离线测试的综合记录，以及最新测试/打包日志。

### `交接与报告/`
保存交接文档、周报、半月报和版本工作总结。

### `参考部署日志/`
保存 CertAgent 项目的部署与排查经验。它不是证书核对工具的运行代码，但其中的 systemd、权限、环境变量和 Linux 排查经验被本项目借鉴。

## 阅读顺序

1. 先读根目录 `项目整理总说明.md`。
2. Windows 使用读 `本地Windows/README.md`。
3. Linux 部署读 `Linux/README.md` 和 `Linux/部署说明.md`。
4. 查看近期状态读 `近期日志/2026-08-26-部署与验证摘要.md`。
5. 查看版本变化读 `本地Windows/交付/历史版本/CHANGELOG.md`。

## 日志整理规则

- 新的服务器部署、网页启动、解密和 UL 验证记录放到 `近期日志/`。
- 每次打包至少保留版本说明和打包日志。
- 业务 Excel 不放日志目录；测试报告只保留不含敏感业务数据的文本摘要。
- 上游 Crawl4AI 的 `CHANGELOG.md` 和 `JOURNAL.md` 保留在项目根目录，不与证书工具日志混合。
