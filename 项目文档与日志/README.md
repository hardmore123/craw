# 项目文档与日志

本目录按 **运行平台** 分为两部分：本地 Windows 相关文档放 `本地版本/`，Linux 服务器相关文档放 `服务器版本/`。

## 目录结构

```text
项目文档与日志/
├─ README.md                     # 本说明
├─ 本地版本/                     # Windows 本地开发、打包、离线测试、周期报告
│  ├─ HANDOFF_交接文档.md         # 新人接手第一篇：本地开发/运行完整说明
│  ├─ 周报_证书核对工具.md
│  ├─ 半月报_证书核对工具.md
│  ├─ v2.7打包日志.txt            # v2.7 交付包打包结果
│  ├─ 自测报告.txt                # 端到端离线自测结果
│  ├─ VDE解析与比对测试报告.txt   # VDE 解析器离线断言测试
│  └─ 导出两表测试日志.txt        # 导出两表脚本本地运行日志
└─ 服务器版本/                   # Linux 服务器部署与验证
   ├─ 2026-08-26-部署与验证摘要.md  # 最近一次 Linux 部署、解密、UL、打包综合摘要
   └─ 参考部署经验CertAgent/       # 另一项目 CertAgent 的部署经验，仅作参考
      ├─ 部署与使用指南.md
      └─ 部署问题排查日志.md
```

## 本地版本（Windows）

面向在本机 Windows（Python 3.12）上做开发、打包和离线验证的人。

- 先读 `本地版本/HANDOFF_交接文档.md`，了解项目位置、依赖、代理、UL 登录和常用命令。
- 周报、半月报记录阶段性进展与计划。
- 三份测试/打包日志是不含敏感业务数据的文本快照，用于回溯验证结果。

## 服务器版本（Linux）

面向在 Linux 服务器（Python 3.11）上部署网页服务、解密服务和 UL 查询的人。

- `2026-08-26-部署与验证摘要.md` 是最新的服务器状态：解密服务、网页服务、Linux UL、VDE/TÜV、systemd 切换待办。
- `参考部署经验CertAgent/` 来自另一个项目 CertAgent，不是本工具的运行代码。其中 systemd、Nginx 权限、环境变量加载、透明加密解密等经验被本项目借鉴，保留作参考。
- 具体部署步骤见根目录 `Linux/README.md` 和 `Linux/部署说明.md`。

## 阅读顺序

1. 根目录 `项目整理总说明.md`（总览）。
2. Windows 使用：`本地Windows/README.md` + `本地版本/HANDOFF_交接文档.md`。
3. Linux 部署：`Linux/README.md`、`Linux/部署说明.md` + `服务器版本/2026-08-26-部署与验证摘要.md`。
4. 版本变化：`本地Windows/交付/历史版本/CHANGELOG.md`。

## 整理规则

- 新的本地打包、离线测试记录放 `本地版本/`。
- 新的服务器部署、网页启动、解密和 UL 验证记录放 `服务器版本/`。
- 业务 Excel 不放日志目录；测试报告只保留不含敏感业务数据的文本摘要。
- 上游 Crawl4AI 的 `CHANGELOG.md` 和 `JOURNAL.md` 保留在项目根目录，不与证书工具日志混合。
