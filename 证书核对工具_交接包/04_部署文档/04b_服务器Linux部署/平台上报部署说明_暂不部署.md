# 证书核对平台上报部署包（暂不部署）

本文件夹仅为服务器待部署文件，不代表已经上传或启用。

## 包含内容

- `cert_verify_platform_report.py`：对应 `cert_verify/platform_report.py`
- `cert_verify_web_tasks.py`：对应 `cert_verify/web/tasks.py`
- `static_app.js`：对应 `cert_verify/web/static/app.js`
- `static_index.html`：对应 `cert_verify/web/static/index.html`
- `certverify.service`：对应服务器 `/etc/systemd/system/certverify.service`
- `PAP.env.example`：平台配置模板，不含真实 API Key
- `部署前信息清单.md`：服务器、端口、平台参数和部署前检查项
- `回滚说明.md`：出现问题时的恢复步骤
- `部署说明.md`：文件映射和部署概要

## 部署时必须保留的路径关系

本包为了便于交接使用了扁平文件名。上传时必须按上面的“对应”路径放回项目目录，不能直接把所有文件混放在 `cert_verify/` 根目录。

## 部署前必须准备

- ProductAgentPlatform 已注册 `cert_verify` agent
- 已取得专用有效 API Key
- 已确认 Collector `http://10.18.87.51:8001` 健康
- 已备份服务器当前代码和 service 文件
- 已确认没有正在运行的证书核对任务

## 服务器部署时

1. 将本包内目录按原路径复制到 `/home/hisense/pro/Gitlab/DataGather/`。
2. 编辑服务器 `.env`，填写 `PAP_ENABLED=true` 和平台管理员提供的专用 `PAP_API_KEY`。
3. 执行 `sudo systemctl daemon-reload` 和 `sudo systemctl restart certverify`。
4. 验证 `http://10.18.87.51/craw/` 和 `/craw/api/ul-status`。

API Key 不在此包中，不要写入代码、service、Git 或聊天记录。
本包不包含 Nginx 网关配置；现有生产方案继续使用 Nginx 80 的 `/craw/`。
