# 本地 Windows 文件区

## 用途

这里保存 Windows 本地使用的交付包、测试输入、导出结果和本地配置说明。

## 目录

- `交付/证书核对工具/`：当前 v2.7 解压即用目录。
- `交付/证书核对工具_v2.7.zip`：最新 Windows 交付压缩包。
- `交付/input/`：本地业务 Excel、样例、导出结果和旧测试脚本。
- `交付/历史版本/`：v2.0、v2.5、v2.6、v2.7 历史归档。
- `配置/`：本地配置提示；真实密钥和代理配置不得提交。

## 推荐使用方式

优先进入 `交付/证书核对工具/`，双击 `一键启动.bat`。不要单独移动其中的批处理、`cert_verify` 或 `_py.bat`。

源码重新打包必须在项目根目录执行：

```powershell
py -3.12 cert_verify\build_package.py
```

打包脚本会自动重建 `本地Windows/交付/证书核对工具/`，并生成 v2.7 zip。若交付目录中有手工文件，请先备份，因为打包会重建当前交付目录。

## 数据安全

`input/` 中的 Excel 可能含制造商、型号和证书业务数据，只用于本地核对；不要上传 GitHub、不要放入 Linux systemd 目录、不要复制进交付 zip。
