# 回滚说明

如果部署后出现异常，先停止服务：

```bash
sudo systemctl stop certverify
```

恢复部署前备份的 `cert_verify/platform_report.py`、`cert_verify/web/tasks.py`、前端文件和 service 文件，然后执行：

```bash
sudo systemctl daemon-reload
sudo systemctl start certverify
sudo systemctl status certverify --no-pager
```

本次代码不修改 Nginx 配置。若仅平台上报异常，可在服务器 `.env` 设置 `PAP_ENABLED=false` 后重启，证书核对功能仍可运行。
